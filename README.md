# Ledington desktop releases

Official Ledington desktop installers and the automatic update feed.

The universal Mac app supports Apple Silicon and Intel Macs running macOS 13 or later. Releases are signed by Fusial LLC and notarized by Apple before publication.

Download [Ledington 0.1.4 for Mac](https://github.com/ledingtonapp/desktop-releases/releases/download/v0.1.4/Ledington_0.1.4_universal.dmg), or browse the [releases page](https://github.com/ledingtonapp/desktop-releases/releases). One installer works on both Mac architectures.

After installing an updater-enabled release (0.1.2 or later), Ledington checks for updates automatically. You can also choose **Ledington → Check for Updates…**. Updates download in the background and install when you quit and reopen the app, after saving your work. Existing Apple Silicon installations can update to the universal app without reinstalling.

Each release includes its installer, signed update archives, update feed, and SHA-256 checksums. The archive with an `aarch64` filename is an identical compatibility copy for older installations. Application source and signing credentials are maintained separately.
