# Ledington desktop releases

Official Ledington desktop installers and the automatic update feed.

The first supported platform is Apple Silicon on macOS 13 or later. Releases are signed by Fusial LLC and notarized by Apple before publication.

Download the [latest Apple Silicon installer](https://github.com/ledingtonapp/desktop-releases/releases/latest/download/Ledington_0.1.2_aarch64.dmg), or browse the [releases page](https://github.com/ledingtonapp/desktop-releases/releases). Ledington 0.1.2 is signed, notarized and available now.

After installing an updater-enabled release (0.1.2 or later), Ledington checks for updates automatically. You can also choose **Ledington → Check for Updates…**. Updates download in the background and install when you quit and reopen the app, after saving your work.

Each release includes its installer, signed update archive, update feed, and SHA-256 checksums. Application source and signing credentials are maintained separately.
